## 3. Investigasi & Resolusi Defect Database (Defect Resolution Log)

- **Nomor Laporan Defect**: `BUG-H17-DB-001`
- **Tingkat Keparahan**: Critical (Severity: High / Impact: Blocker untuk Tambah Aset)
- **Gejala Kesalahan**: Saat teknisi/user mencoba menyimpan perangkat baru dari modal dashboard, sistem backend mengembalikan status HTTP `500 Internal Server Error` dengan log kesalahan:
  ```text
  Internal server error: Unknown column 'sub_category' in 'field list'
  ```
- **Akar Masalah (Root Cause)**: File backend [`taims-backend/src/routes/assets.js`](file:///C:/Users/ThinkPad/Documents/project%20T-AIMS/taims-backend/src/routes/assets.js) telah mengimplementasikan field `sub_category` pada query `INSERT INTO assets`, namun tabel fisik `assets` pada MariaDB `taims_db` belum memiliki kolom tersebut akibat desinkronisasi migrasi awal.
- **Tindakan Perbaikan**:
  1. Melakukan alter tabel langsung di engine MariaDB:
     ```sql
     ALTER TABLE assets ADD COLUMN sub_category VARCHAR(150) NULL AFTER category;
     ```
  2. Melakukan export / dump ulang master schema ke file [`database/taims_db.sql`](file:///C:/Users/ThinkPad/Documents/project%20T-AIMS/database/taims_db.sql).
- **Hasil Pengujian Ulang (Retest Result)**:
  - Eksekusi request `POST http://localhost:3000/api/assets` menghasilkan respon:
    ```json
    { "success": true, "message": "Perangkat berhasil ditambahkan", "id": 16 }
    ```
  - Status Bug: **CLOSED & VERIFIED FIXED**.
