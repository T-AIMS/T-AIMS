1 Uraian Teknis Tugas yang Selesai Dikerjakan

A. Implementasi Gateway Alert Email via SMTP (Checklist 5.5 & Dokumen PKL Hal. 11)

1. Pembangunan Service Modul Nodemailer (email-service.js): Mengembangkan modul perantara pengiriman surel darurat pada backend Express.js berbasis protokol SMTP terenkripsi (Port 465 SSL atau Port 587 STARTTLS) dengan konfigurasi dinamis via .env.

2. Desain Template Kartu Email Insiden (HTML Enterprise Template): Merancang template email responsif berstandar NOC modern: header dinamis bergradien merah untuk status CRITICAL OFFLINE, kuning/oranye untuk ANOMALY WARNING, dan hijau untuk RECOVERY RESOLVED. Kartu email merangkum atribut krusial: Kode Aset, Nama Perangkat, IP Address, Kategori, Lokasi Ruangan, Waktu Insiden (WIB), PIC Teknis, dan tombol CTA [ Buka Dashboard T-AIMS Live ].

3. Integrasi Non-Blocking Pipeline Notifikasi: Menghubungkan fungsi sendIncidentAlertEmail ke dalam dispatchTelegramAlert di notifications.js. Pemanggilan dieksekusi secara asynchronous non-blocking dengan safety-timeout 10 detik agar kegagalan jaringan SMTP pihak ketiga tidak mengganggu latensi bot Telegram n8n.

B. Resolusi & Perbaikan Bug Web Produksi (Web & System Bug Fixing)

1. Proteksi RBAC UI — Sembunyikan Tombol Aksi untuk Role User: Mengatasi kerentanan otorisasi antarmuka di mana akun ber-role biasa (user/guest) masih sempat melihat tombol aksi Edit dan Hapus pada tabel perangkat. Diberlakukan filter ketat pada renderFullDevicesTable di app.js: jika bukan admin/superadmin, tombol edit dan hapus sama sekali tidak dimasukkan ke dalam DOM, tombol + Tambah Aset disembunyikan, dan fungsi openQuickStatusModal dikunci.

2. Eliminasi Stale Caching Browser (Cache-Busting Integration): Mengatasi isu browser klien yang mempertahankan cache skrip lama dengan memperbarui query parameter berkas di index.html menjadi app.js?v=20261101_H21 serta menginjeksi response header Cache-Control: no-cache, no-store, must-revalidate pada backend Express.

3. Resolusi Notifikasi Dobel / Spam Pesan Kembar di Telegram: Menghilangkan duplikasi pengiriman pesan notifikasi yang sebelumnya menembak ke webhook n8n sekaligus Direct Telegram API. Alur pengiriman kini dipusatkan 100% 1 PINTU murni melalui n8n AI Engine Runner port 5678.

4. Startup Grace Period 60 Detik (Anti-Restart Flapping Buffer): Menambahkan buffer jeda selama 60 detik pada offline-checker.js saat backend baru menyala, mencegah timbulnya false alarm untuk CCTV-01 & RTR-01 akibat pemeriksaan offline instan sebelum paket ping ICMP pertama terkirim.
