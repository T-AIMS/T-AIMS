## 3. Investigasi & Resolusi Defect Tampilan SLA (Defect Resolution Log)

- **Nomor Laporan Defect**: `BUG-H18-UI-001`
- **Tingkat Keparahan**: Medium (Severity: Medium / Impact: Visual Glitch pada Bar Uptime SLA)
- **Gejala Kesalahan**: Pada modul *System Availability & SLA Summary â€¢ 30 Days*, teks persentase uptime per site muncul (contoh: *Marketing Office 91.7% Uptime*, *Head Office 26.6% Uptime*), namun garis batang indikator warna (merah/kuning/hijau) di bawah teks tidak terlihat sama sekali (hanya garis rel abu-abu gelap kosong).
- **Akar Masalah (Root Cause)**: Pada stylesheet [`frontend/assets/css/style.css`](file:///C:/Users/ThinkPad/Documents/project%20T-AIMS/frontend/assets/css/style.css), elemen container `.sbi-track` memiliki `height: 6px`, namun class anak `.sbi-prog` tidak memiliki properti tinggi (`height`). Karena elemen `div` anak kosong tanpa isi teks, tinggi efektifnya menjadi `0px`, sehingga lebar warna persentase (`style="width: 91.7%"`) tidak dapat dirender secara visual oleh browser engine.
- **Tindakan Perbaikan**:
  1. Menambahkan pendefinisian tinggi eksplisit dan transisi halus pada class `.sbi-prog`:
     ```css
     .sbi-track { height: 6px; background: rgba(255, 255, 255, 0.08); border-radius: 3px; overflow: hidden; position: relative; }
     .sbi-prog { height: 100%; border-radius: 3px; transition: width 0.3s ease; }
     ```
  2. Melakukan sinkronisasi file stylesheet dan menguji ulang pemuatan halaman.
- **Hasil Pengujian Ulang (Retest Result)**:
  - Batang warna indikator SLA (merah untuk Head Office 26.6%, kuning untuk Marketing Office 91.7%, dan merah untuk House of Server 6.7%) kini tampil proporsional mengisi rel abu-abu secara sempurna.
  - Status Bug: **CLOSED & VERIFIED FIXED**.
