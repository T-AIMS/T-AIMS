| **DEF-H21-001** | Device Detail & Monitoring Engine | **False-Positive Offline & Ketiadaan Anti-Spam Debounce pada Tombol "Uji Ping Sekarang"**: Penekanan tombol `[ Uji Ping Sekarang ]` pada Modal Detail Perangkat memicu ICMP ping langsung dari Cloud VPS ke IP privat LAN (`192.168.x.x`) yang berujung RTO. Frontend dan backend sempat menjatuhkan status perangkat yang tadinya ONLINE menjadi OFFLINE secara keliru (*flapping*), memicu notifikasi peringatan ke Telegram, serta tombol dapat di-spam tanpa batas jeda (*cooldown*). | **Medium** | **RESOLVED & HARDENED** | Telah diimplementasikan perbaikan terpadu: (1) Countdown timer 5-detik (*Jeda Anti-Spam*) pada elemen tombol UI dengan status `disabled`, (2) Rate-limiting cache 3-detik pada backend API `/real-ping`, (3) Pencegahan mutasi status master aset dan pencegahan false-alarm Telegram pada uji manual, dan (4) Smart Hybrid Fallback untuk mempertahankan status Online perangkat privat LAN. |
