# Presentation & Demonstration Materials

Direktori ini disiapkan untuk menampung materi presentasi resmi dan rekaman demonstrasi sistem **T-AIMS (Teknolab Asset & Infrastructure Monitoring System)**.

---

## 📌 Ruang Lingkup Materi:
1. **Slide Presentasi Sidang PKL:** Berkas PowerPoint (`.pptx` / PDF) yang merangkum arsitektur, integrasi 11 personel tim, hasil pengujian, dan analisis ketersediaan infrastruktur.
2. **Video Demonstrasi Sistem:** Rekaman video end-to-end uji coba pemantauan hardware nyata (ESP32, RPi, IP CCTV) serta simulasi pemulihan kegagalan (*Failure Simulation*).
3. **Dokumen Evaluasi Akhir:** Berita acara pengujian bersama pembimbing lapangan PT Teknolab Caraka Internasional.

*Direktori ini aktif digunakan menjelang Milestone Final Demo Day 30.*
