# Database Folder

Folder ini berisi file SQL untuk setup, backup, dan migrasi database T-AIMS.

## File

- `schema.sql` — Struktur tabel (DDL)
- `seed.sql` — Data contoh (DML)
- `taims_db.sql` — Full dump (backup lengkap)
- `audit_aset.sql` — Query audit
- `seed_data_update.sql` — Draft update
- `audit_aset_backup.sql` — Backup file audit
- `migrations/` — Folder file migrasi
