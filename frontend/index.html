Aturan Standar Penentuan Status Perangkat

Status TERHUBUNG:

Perangkat merespons ping ≤ 100 ms atau denyut sinyal diterima dalam interval ≤ 30 detik tanpa kegagalan.

Status PERINGATAN:

Latensi > 100 ms, paket hilang > 10%, atau gagal merespons pada percobaan ke-1 dan ke-2 (Penghitung Coba Ulang > 0).

Status TERPUTUS:

Gagal merespons 3 kali berturut-turut (Maksimal Coba Ulang: 3x), batas waktu > 1500 ms, atau denyut sinyal berhenti > 60 detik.

Status TIDAK DIKETAHUI:

Perangkat non-jaringan atau belum pernah terdeteksi sejak inisialisasi sistem pertama kali.

MQTT service Port 1883 terminated. Health check matrix reports degraded telemetry pipeline.

Scenario 4 Raspberry Pi Server Failure

Raspberry Pi server node powered down. Heartbeat fails and status switches to OFFLINE.

Scenario 5 REST API Service Outage

Endpoint /api/health unresponsive. HTTP matrix detects 500 error / Connection Refused.

Recovery System Failback & Recovery

All services restored. System logs recovery state and sends resolved alert notification.
